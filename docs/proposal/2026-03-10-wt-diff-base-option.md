# `wt diff --base` によるベースブランチからの全体差分表示

## Summary
現在のワークツリーでの作業全体（未コミットの変更だけでなく、このブランチで積んだすべてのコミット）をレビューするために、ベースブランチとの差分（`git diff <base-branch>...HEAD`）を簡単に表示できる `--base` オプションを `wt diff` に追加する提案。

## Problem
現在の `wt diff` は `git diff` のラッパーであり、まだコミットしていないローカルの変更（Working tree と HEAD の差分）を表示します。
しかし、一つのタスク（Worktree）での作業が完了し、「さて PR を出すぞ」または「これまでの作業全体を振り返るぞ」という時、ユーザーが本当に見たいのは「このワークツリー（ブランチ）で追加したすべての変更」であることが多いです。
通常、これを実現するには `git diff main...HEAD` や `git diff origin/main...HEAD` などを手打ちする必要がありますが、リポジトリごとにベースブランチが `main` だったり `develop` だったりするため、毎回それを意識して入力するのは開発体験上の摩擦（コンテキストスイッチ）を生みます。

## Proposal
`wt diff` コマンドに `--base` オプションを追加し、現在のワークツリーの起点となったベースブランチ（デフォルトでは `main` や設定されたデフォルトブランチ）と `HEAD` との差分を自動で計算して表示するようにします。

**挙動:**
- `wt diff --base`
  内部で `git diff $(wt_get_default_branch)...HEAD` に相当するコマンドを実行します。
- `lumen` との統合
  `wt config diff.tool lumen` が設定されている場合、`lumen diff <base-branch>...HEAD` として呼び出され、リッチな UI で PR 全体の差分をターミナル上でレビューできます。

## Inspiration
- **`gh pr diff`**: PR の差分を表示してくれますが、まだ push していないローカルのコミットや WIP 状態の変更も含めて見たい場合には使えません。
- **Git Town (`git town diff`)**: 自身のブランチとメインブランチの差分を賢く表示する機能があり、これに似た DX を目指します。

## Expected Daily Benefit
タスクの区切りや、PR 作成直前のセルフレビューが `wt diff --base` 一発で可能になります。
特に `lumen` などのリッチな diff ツールと組み合わせることで、ターミナル上で極めて快適に「このワークツリーで何を変えたか」の全貌を俯瞰でき、typo や不要な console.log 等の消し忘れに気付きやすくなります。日々のブランチ作業の「最後の仕上げ」の摩擦が大きく減ります。

## Scope and Non-Goals
- **Scope**: `wt diff` に `--base` オプションを追加し、ベースブランチを自動解決して `git diff` または設定された `diff.tool` に渡す機能。
- **Non-Goals**: 高度な差分比較ツールそのものを作ること。あくまで Git や Lumen に適切な引数（`...HEAD`）を渡すラッパーとしての機能に留めます。

## Risks or Open Questions
- **ベースブランチの自動解決**: リポジトリのデフォルトブランチ（`main` や `master`）以外から分岐したワークツリー（例: `develop` から分岐したフィーチャーブランチ）の場合、どのブランチをベースとして差分を取るべきかの判定が難しい場合があります。まずはリポジトリのデフォルトブランチをベースとするシンプルな実装から始めるのが良いかもしれません。
- **未コミットの変更を含めるか**: `git diff main...HEAD` に加えて、現在の Working tree の変更（`git diff HEAD`）も一緒に見たい場合、どう表現するか？（Git の仕様上、`main...HEAD` はコミット間の差分なので、未コミットの変更はそのままでは含まれません）。必要であれば、未コミットの変更も含めた `git diff main` （スリードドットではなくツードット相当）を採用するなどの検討が必要です。

## Suggested Rollout
1. リポジトリのデフォルトブランチを取得するヘルパー処理を整備する。
2. `wt diff --base` が呼ばれた際、`git diff <default-branch>...HEAD` を実行するよう実装する。
3. `diff.tool` (lumen 等) が設定されている場合にも正しく引数が引き継がれることを確認する。
