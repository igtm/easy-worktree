# `wt rm` / `wt clean` 時のローカルブランチ自動削除 (Auto-delete branch on remove)

## Summary

`wt rm` や `wt clean` コマンドでワークツリーを削除した際、そのワークツリーに関連づいていたローカルブランチも同時に削除する機能の提案です。

## Problem

現在、`wt rm feature-A` や `wt clean --merged` を実行すると、ワークツリーのディレクトリ自体（および Git のワークツリー管理情報）は綺麗に削除されますが、関連づいていた Git のローカルブランチ（`feature-A`）は削除されず、そのまま `git branch` に残り続けます。
日常的に `easy-worktree` を使ってタスクごとにブランチとワークツリーを作成していると、いつの間にか大量の「ワークツリーを持たない古いローカルブランチ」がローカルリポジトリに溜まってしまいます。これにより、シェルのブランチ補完が遅くなったり、`git branch` の視認性が著しく低下し、定期的に手動で `git branch -D` を実行するお掃除作業が必要になるという摩擦が生じています。

## Proposal

以下の機能を追加し、ワークツリーとローカルブランチのライフサイクルを一致させます。

1. **`wt rm <name>` へのブランチ削除の統合**
   - ワークツリー削除の成功直後に、元のブランチを対象に `git branch -d <branch_name>` を試行します。
   - コミットが未マージなどの理由で失敗した場合でも、`wt` 自体はエラー終了させず、「警告: ブランチの削除はスキップされました」というメッセージのみを出力します。
   - `wt rm <name> --delete-branch` のような明示的なフラグを追加するか、設定ファイルでのオプトイン/オプトアウトを可能にします。

2. **`wt clean` 系コマンドでの一括クリーンアップ**
   - `wt clean --merged` や `--closed` 実行時も同様に、削除対象となったワークツリーのブランチを一括で削除します。

3. **コンフィグによる挙動の制御**
   - `wt config rm.delete_branch true` などの設定値を提供し、デフォルトでローカルブランチも一緒に消し去る直感的な挙動を選択できるようにします。

## Inspiration

- `gh pr close --delete-branch` や GitHub UI 上での「Merge 後のブランチ自動削除」のような、ユーザーに掃除の手間をかけさせないシームレスな体験。
- タスク完了と同時に作業コンテキスト（ディレクトリ＋ブランチ）が完全に消滅する、認知負荷の低い状態管理。

## Expected Daily Benefit

「ワークツリーを消せば、関連するローカルブランチも消える」という直感的なライフサイクルが実現します。
無駄な古いブランチが蓄積しなくなるため、常に `git branch` が綺麗な状態に保たれ、新しい作業へのコンテキストスイッチや補完操作が軽快になります。

## Scope and Non-Goals

- **Scope**:
  - `git branch -d` または `-D` を用いたローカルブランチの削除機能。
- **Non-Goals**:
  - **リモートブランチの削除**: `origin/feature-A` などのリモートブランチの削除は本機能のスコープ外とします（リモートの削除は `gh pr merge` 等の別のツール・層の責務とするため）。

## Risks or Open Questions

- **削除対象ブランチの特定**: ワークツリーを削除する直前に、そのワークツリーが現在チェックアウトしているブランチ名を正確に取得しておく必要があります（`git worktree list` などから）。
- **デフォルト挙動の判断**: 破壊的変更になり得るため、最初は `--delete-branch` フラグによる明示的な実行、または設定でのオプトイン機能として導入し、安全性が確認されてからデフォルト化（またはプロンプトでの `[Y/n]` 選択）を検討するのが良いと思われます。

## Suggested Rollout

1. `wt rm` コマンドに `--delete-branch` (エイリアス `-d`) オプションを実装する。
2. コマンドライン引数を省略しても適用できるよう、`config.toml` に `rm.delete_branch` 設定を追加する。
3. `wt clean` コマンドにおけるブランチ自動削除オプションへの対応を追加する。
