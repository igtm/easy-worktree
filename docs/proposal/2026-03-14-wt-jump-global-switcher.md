# `wt jump` コマンドによるグローバルなワークツリー切り替え機能の追加

## Summary
現在のリポジトリ内に限らず、これまでに `easy-worktree` で管理している **すべてのリポジトリ** のワークツリーを横断して検索し、ディレクトリの場所を問わず一発でジャンプ（切り替え）できる `wt jump`（または `wt select --global`）コマンドを追加する。

## Problem
複数のプロジェクト（リポジトリ）を並行して開発している際、別のリポジトリの特定の機能ブランチ（ワークツリー）に移動したくなる場面がよくある。
現状では、まずそのプロジェクトのルートディレクトリに移動してから `wt select` を実行するか、長い絶対パスを直接打ち込む必要がある。
例:
```bash
cd ~/projects/api-server
wt select feature-foo
```
「あのリポジトリのあのブランチで作業したい」と思ったときに、ディレクトリ階層を意識して移動するステップを挟むのは、思考の妨げ（摩擦）になり、日々の小さなストレスとなる。

## Proposal
どのディレクトリからでも、すべての管理下リポジトリのワークツリーを一覧表示・インクリメンタルサーチでき、選択すると即座にそのワークツリーへ切り替わる `wt jump` コマンドを提案する。

**挙動のイメージ:**
1. `easy-worktree` を使って作業（`wt init`, `wt clone`, `wt select` など）を行うたびに、対象リポジトリのルートパスがグローバルなレジストリファイル（例: `~/.config/easy-worktree/registry.json`）に自動記録される。
2. ユーザーが任意の場所で `wt jump` を実行すると、レジストリに登録された全リポジトリの全ワークツリーが `fzf` 等のUIでフラットに一覧表示される。
   表示例:
   ```
   api-server    (main)
   api-server    [feature-foo]
   web-frontend  (main)
   web-frontend  [hotfix-bar]
   my-library    [pr@123]
   ```
3. 選択すると、現在のディレクトリがどこであっても、対象リポジトリの対象ワークツリーへ瞬時にジャンプする（通常の `wt select` と同様に新しいシェルプロセスとして起動）。

## Inspiration
- `zoxide` や `ghq`、`tmux-sessionizer` のような、ディレクトリパスの概念を意識させないグローバルなジャンプ体験。
- プロジェクト（リポジトリ）とブランチ（ワークツリー）の移動を1アクションに統合した、高度なインクリメンタルサーチ。

## Expected Daily Benefit
ターミナルを開いた直後や、バックエンドの実装中にフロントエンドの関連ブランチをサッと開きたいときなど、一切のパス入力（`cd` や `ls`）をせずに目的の環境に到達できるようになり、コンテキストスイッチのコストが劇的に下がる。

## Scope and Non-Goals
- **対象リポジトリ**: システム全体を `find` で検索すると遅すぎるため、あくまで `easy-worktree` が一度でも動作してレジストリにキャッシュされたリポジトリのみを対象とする。
- **UIの複雑化**: TUIのような高度な管理機能は持たせず、純粋に「一覧から選んで移動する」だけのシンプルな機能に留める。

## Risks or Open Questions
- **レジストリのクリーンアップ**: リポジトリのディレクトリが手動で削除（`rm -rf`）された場合、レジストリに無効なパスが残る。リストの表示時に存在確認を行い、見つからなければ適宜レジストリから自動でパージする仕組みが必要。
- **コマンド名の選定**: `wt jump` という専用コマンドにするか、あるいは既存の `wt select` を拡張して `wt select --global`（オプション）として提供し、ユーザーにシェルのエイリアス登録を委ねるか。

## Suggested Rollout
1. まず、`wt` の各種コマンド実行時に、バックグラウンドでリポジトリのルートパスをグローバルレジストリ（JSONやテキスト）に追記・キャッシュする機構を実装する。
2. レジストリを読み込み、有効なパス配下にあるワークツリーをすべて列挙する `wt jump` を実装する。
3. 無効なパス（削除済みリポジトリ）を検知して自動クリーンアップするロジックを追加する。
